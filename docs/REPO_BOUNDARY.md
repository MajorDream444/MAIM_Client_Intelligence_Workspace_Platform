# Repository Boundary

Status: canonical

This repository exists to build the MAIM Client Intelligence Workspace Platform as a reusable product.

## Product Boundary

The platform provides reusable structure.

Client workspaces provide client-specific truth.

```txt
Platform owns:
shared workspace model
client dashboard shell
knowledge vault pattern
AI coach pattern
reports
client templates
routing and metadata

Client owns:
brand
content
journey
deliverables
doctrine
roadmap
client-specific assets
```

## Sheetal / Shakti Boundary

Sheetal can be Client #001.

Shakti materials may inform the first workspace.

But Shakti is not the platform.

Do not generalize sacred, practitioner-specific, or client-specific doctrine into generic platform language unless it has been deliberately approved as a reusable MAIM pattern.

## Ecosystem Boundary

```txt
MAIM teaches.
HAMAL orchestrates.
AMA agents operate.
Hanzo provides AI infrastructure.
Lux provides sovereignty.
This repo provides the reusable client intelligence workspace product.
```

## Implementation Boundary

Do not start from a dashboard build.

The first accepted order is:

1. Platform architecture.
2. Workspace product specification.
3. Client #001 configuration and roadmap.
4. Frontend MVP shell.
5. AI and data layer.

## Human Approval Boundary

Client doctrine, client deliverables, client assets, and externally visible copy require human review before publication or migration.
